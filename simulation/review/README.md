# Review materials

Documents for the revision of the manuscript *A Closed-Loop Framework for Knowledge-Based Causal Model Refinement Using Process Mining and Human–AI Governance*.

| File | What it is |
|---|---|
| `Response_to_Reviewers.docx` / `.md` | Point-by-point response to Reviewers 1–4, with a status for every comment (Done / Partly / Not done / Author action) |
| `Manuscript_Change_List.docx` / `.md` | Tracked edits, simulation changes, items needing the authors, items not done |
| `Report_Simulation_Manuscript_Changes.docx` | Detailed report: simulation changes, manuscript changes, and how the results changed (before vs after) |

All numbers in these documents are read from `../results/` (M = 500 replications, master seed 20260610). The revised manuscript PDFs (tracked, clean, and a redline against v3) are kept outside the repository.

Note: this is a known-answer (positive-control) test on a use case whose results were already published by the authors; no human or LLM adjudication is simulated.
