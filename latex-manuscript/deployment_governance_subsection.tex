\subsection{Deployment Governance and Privacy Safeguards}
\label{sec:deployment_governance}

To address data sovereignty, privacy compliance, and epistemic reliability in AI-assisted observational workflows, the closed-loop framework enforces strict governance protocols across data egress, model provenance, prompt security, and clinical accountability:

\begin{enumerate}
    \item \textbf{Data Boundary and API Minimisation:} Raw, patient-level longitudinal records---including patient identifiers, individual encounter dates, specific lab test measurements, and granular demographic histories---are strictly isolated within the secure institutional environment and are never transmitted to external APIs. In Phase 3 and Phase 4, outbound payloads sent to large language model (LLM) services are strictly restricted to: (i) abstract node and edge labels (e.g., ``CKD progression'', ``CVAE'', ``Death''); (ii) aggregated process-mining transition summaries (transition counts, antecedent-conditional frequencies, and median inter-event durations with interquartile ranges); and (iii) formal graph structural representations (adjacency matrices and backdoor adjustment sets). All patient-level event extraction, SQL querying, directly-follows graph (DFG) discovery, and survival model estimations are executed locally in the browser or institutional host runtime.
    
    \item \textbf{Model-Version Pinning:} To guard against behavioural drift and silent deprecation inherent in commercial LLM APIs, the system enforces strict model-version pinning. In the primary demonstration, requests are pinned to dated snapshot identifiers (\textit{gemini-2.5-flash-001} via Google AI Studio and \textit{gpt-4o-mini-2024-07-18} via the OpenAI API) with fixed sampling hyperparameters (temperature $T = 0.0$ for deterministic proposal generation, $T = 0.2$ for rationale synthesis, top-$p = 0.95$). Dynamic aliases (e.g., \texttt{latest}) are disallowed to guarantee that historical decision provenance logs remain auditable and replicable.
    
    \item \textbf{Privacy Safeguards and Local Deployment:} For strictly air-gapped clinical settings governed by stringent data protection mandates (e.g., European General Data Protection Regulation [GDPR], US Health Insurance Portability and Accountability Act [HIPAA], or Swedish Ethical Review Authority requirements), the tool provides complete support for locally hosted open-weight models via Ollama (e.g., \textit{Llama-3-8B-Instruct}, \textit{Mistral-7B-Instruct-v0.3}) coupled with local vector embedding engines (e.g., \textit{all-MiniLM-L6-v2}). In this zero-egress configuration, no telemetry, prompt payloads, or network tokens leave the local execution perimeter, removing the necessity for third-party business associate or data processing agreements.
    
    \item \textbf{Controls Against Prompt Injection:} When retrieving external literature or domain guidelines to populate the Retrieval-Augmented Generation (RAG) knowledge base, the framework mitigates indirect prompt injection threats. Retrieved texts are treated as untrusted data inputs: they are encapsulated within immutable delimiter boundaries (XML tags), stripped of executable markup, and isolated from system-instruction channels. Furthermore, model outputs are constrained to strictly validated JSON schemas; candidate proposals containing unrecognised actions, malicious instruction overrides, or arbitrary script executions are rejected by schema validators prior to presentation in the governance interface.
    
    \item \textbf{Human Adjudication and Named Accountability:} The operational principle of the framework is strictly asymmetric: \textit{AI proposes, humans decide}. LLM suggestions, confidence ratings, and automated literature rationales possess no autonomous authority over the causal graph. Every proposed DAG modification (node addition, edge insertion, edge removal, or role re-classification) must be explicitly reviewed, validated against biological plausibility, and adjudicated by named human experts. Responsibility for every accepted change recorded in the immutable audit trail rests exclusively with the designated clinical and methodological adjudicators (in this case study, Dr.~F.~Abtahi and Dr.~E.~Illueca).
\end{enumerate}
